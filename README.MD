## 高斯-喬登消去法: [程式碼](https://github.com/CHUANG-CR/Linear-Algebra/blob/main/Gauss-Jordan.cpp)
>**功能概述**：將任意矩陣透過基本列運算，化簡為**簡化列梯形矩陣**。
### **實作細節與邏輯**：
  * 演算法的核心在於逐行尋找並確立前導 1。
  * 在處理過程中，若在當前列的目標位置找不到前導 1，程式的處理邏輯會往下搜尋下一行來尋找非零元素，並透過列交換來繼續運算，確保化簡過程不會中斷。
  * 透過雙層或三層迴圈將主對角線以外的元素皆化為 0，為後續解線性聯立方程組奠定基礎。

## 反矩陣計算: [程式碼](https://github.com/CHUANG-CR/Linear-Algebra/blob/main/Inverse.cpp)
>**功能概述**：計算給定之非奇異方陣的反矩陣。
### **實作細節與邏輯**：
  * 演算法利用了高斯-喬登消去法的延伸應用：建立一個增廣矩陣，將原矩陣與同維度的單位矩陣並排。
  * 對整個增廣矩陣持續進行基本列運算。當左半部的矩陣成功轉換為單位矩陣右半部原本的矩陣就會同步轉換為我們所求的反矩陣。
  * 程式中隱含了可逆性的檢查，若在化簡過程中左側出現全為 0 的列，即代表該矩陣不可逆（奇異矩陣）。

## 行列式值計算: [程式碼](https://github.com/CHUANG-CR/Linear-Algebra/blob/main/Determinant.cpp)
>**功能概述**：計算方陣的行列式值。
### **實作細節與邏輯**：
  * 實作上透過高斯消去法的概念，將原矩陣逐步化為**上三角矩陣**。
  * 當矩陣轉換為上三角形式後，主對角線上所有元素的**乘積**即為該矩陣的行列式值。
  * 程式中需要特別追蹤並紀錄「列交換」的次數：根據線性代數定理，每進行一次列交換，行列式的值就必須乘上 -1，這是維持最終計算結果正確性的關鍵。

## 葛蘭-史密特正交程序: [程式碼](https://github.com/CHUANG-CR/Linear-Algebra/blob/main/Gram-Schmidt.cpp)
>**功能概述**：將輸入矩陣的行向量進行正交化，輸出同維度的正交矩陣。
### **實作細節與邏輯**：
  * **投影扣除**：基於向量投影原理，將當前向量扣除在所有「已正交化向量」上的投影，確保彼此互相垂直。
  * **處理線性相依**：支援向量個數大於空間維度（$n > m$）的輸入，多餘的線性相依向量會自動化簡為零向量。
  * **數值穩定性**：具備防呆機制，當向量長度極小（小於 `1e-9`）時自動跳過投影運算，避免「除以零」的錯誤。
  * **模組化設計**：將內積、純量乘法與向量減法等核心數學運算獨立封裝為輔助函式，提升程式碼可讀性。

## 雷建德多項式正交性驗證: [程式碼](https://github.com/CHUANG-CR/Linear-Algebra/blob/main/Legendre-Verification.cpp)
>**功能概述**：利用離散點的內積與葛蘭-史密特正交化，驗證標準基底 $(1, x, x^2)$ 可轉換為雷建德多項式的正交基底 $(1, x, x^2 - 1/3)$。
### **實作細節與邏輯**：
  * **離散取樣**：在 $[-1, 1]$ 區間內均勻取樣 101 個點，將連續函數轉換為 $\mathbb{R}^{101}$ 空間中的高維向量。
  * **內積逼近積分**：透過計算這 101 維向量的內積，在數值上等效於逼近連續函數的積分運算 ($\int_{-1}^{1} f(x)g(x)dx$)。
  * **正交化驗證**：將取樣矩陣代入葛蘭史密特程序中，印出結果可觀察到正交化後的第三個向量 $U_2$ 高度吻合理論值 $x^2 - 1/3$，成功以數值方法驗證函數空間的正交性質。
